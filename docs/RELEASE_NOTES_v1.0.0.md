# Liner Importer v1.0.0

Первый публичный выпуск проекта **Liner Importer — VK & Yandex Music**.

## Что вошло

- **Экспорт VK Музыки:** JavaScript-скрипт для страницы `m.vk.ru`, выгрузка исполнителей и названий треков в TXT.
- **Экспорт Яндекс Музыки:** Python-скрипт для сохранения избранного и плейлистов в CSV.
- **Импорт в YouTube Music:** поиск совпадений, оценка достоверности и обработка спорных версий песен.
- **Режим Liner:** разбиение подтверждённых песен на плейлисты по 900 треков.
- **Плейлисты «На проверку»:** отдельные списки для ручной очистки сомнительных совпадений.
- **Возобновление работы:** локальное сохранение прогресса, отчёты и повторный запуск без намеренного дублирования.
- **Документация:** русский README, инструкция по установке для Windows и примеры файлов.
- **Иллюстрации:** обложка проекта и схема переноса.

## Быстрый старт

1. Скачайте прикреплённый ZIP-архив и распакуйте его.
2. Установите Python 3.11+.
3. Откройте `ЗАПУСТИТЬ_WINDOWS.bat` или `START_WINDOWS.bat`.
4. Следуйте руководству [README](https://github.com/kolbaska11/liner-importer-vk-yandex-music#readme) для экспорта, авторизации и переноса.

## Важно знать

- Это **неофициальный** проект, не связанный с VK, Яндексом, Google, YouTube Music или Liner.
- Программа не копирует аудиофайлы: переносит списки треков и создаёт плейлисты на основе найденных совпадений.
- Успех поиска и добавления треков зависит от каталога и изменений неофициальных API.
- Перенос полученных плейлистов в Liner производится из YouTube Music.
- Токены, Cookie и личные данные авторизации **не входят** в ZIP и не должны публиковаться.
