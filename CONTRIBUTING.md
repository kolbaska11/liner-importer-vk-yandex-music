# 🤝 Contribution guide

Спасибо за вклад в проект!

1. Создайте отдельную ветку `feature/...` или `fix/...`.
2. Добавьте тесты для исправленного сценария и запустите `python -m unittest discover -s tests -v`.
3. Не загружайте Cookie, OAuth-токены, личные TXT/CSV, ID частных плейлистов, SQLite и запросы cURL с авторизацией.
4. Описывайте совместимость с конкретными версиями `ytmusicapi` и `yandex-music`.
5. При исправлении авторизации проверяйте отдельно чтение и **запись** на тестовом плейлисте (не автоматизируйте в CI).

Файлы пользователя и локальное состояние перечислены в `.gitignore`.
